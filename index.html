업데이트 내역

맥에서 실행하는 법
  1. 받은 zip 을 더블클릭해서 풀어요.
  2. TorangTorang 을 오른쪽 클릭 → 열기 → 열기 (처음 한 번만). 아직 개발자 서명이 없어서 그냥 더블클릭하면 경고가 떠요.
  3. 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 그래도 열기.
윈도우에서 실행하는 법
  1. 받은 zip 을 오른쪽 클릭 → 압축 풀기 (zip 안에서 바로 실행하면 안 돼요).
  2. 풀린 폴더의 TorangTorang.exe 실행.
  3. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
조작법
  1. 키보드·마우스: 방향키 이동, A 상호작용·공격 (앞에 말 걸 대상이 있으면 상호작용), 마우스 왼쪽 공격·도구, Q W E R 스킬, Esc 메뉴 (설정에서 그래픽·언어)
  2. 게임패드: 왼쪽 스틱 이동, A 상호작용, X 공격, Start 메뉴 — 메뉴는 십자 버튼으로 골라요
  3. 게임이 끊기면 Esc → 설정 → 그래픽 → 단계를 낮춰 보세요.
